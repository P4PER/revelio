Four things go wrong often enough to be worth writing down. Each one has a cause
and a fix.

## The commands do not appear

Typing `/` in a server the bot is in should list `card`, `search`, `deck`,
`collection` and `mydecks`. If it does not:

- **Give it a moment, then restart your Discord client.** The bot publishes its
  command list to Discord every time it starts, and your client caches that list.
  A restart is what refreshes it.
- **Check the bot is actually in that server.** The commands are published to the
  bot, so they only show up where the bot has been added. The install link is on
  the [Discord bot page](/discord), and adding it needs the Manage Server
  permission.
- **A stale list is possible.** If publishing the command list fails, the bot
  logs it and keeps running on the previously published set rather than refusing
  to start - so it can be online and answering while showing a list that is one
  version behind. The next successful start fixes it.

## It says I need to link my account

`/collection` and `/mydecks` answer about you, so they need to know who you are.
The reply carries a direct link to the Settings page where you link up. See
[account linking](/docs/discord/linking) for the walkthrough.

Already linked and still asked? Two possibilities. You may be using a different
Discord account from the one you linked - the link is to one specific Discord
account, not to your name. Or the Revelio account behind it has been suspended: a
suspension is checked here too, so a banned account is refused in Discord the same
way it is on the website.

## A deck is not found

`/deck` finds public decks, and your own private decks once your Discord account
is linked. Someone else's private deck is not found, and the reply does not say
whether it exists.

If you typed a name, pick it from the suggestions rather than sending the text:
a picked suggestion is always the exact deck. Otherwise, paste the whole deck
link rather than retyping the id by hand; the full link cannot be mistyped.

## "I can't post in this channel"

**Post publicly**, **Post to channel** and **Share** send a normal message in the
channel, so the bot needs to be allowed to: view the channel, send messages (or
send messages in threads, inside a thread) and embed links, and attach files for
a deck. A server's moderators
can grant these to the Revelio role, or in the channel's own permissions. Until
then, **Only show me** still works there.

If it says "I can't post here" instead, there is no channel the bot can reach:
for example a server where only you added Revelio, rather than the server
itself. Run `/deck` again and choose **Only show me**; in the browsers,
everything you looked at privately still works, and only posting does not. In a direct message with
the bot, your own private decks are shown to you straight away, without asking.

## A page of results is empty

Page forward through `/search` and the last page may say there are no more
results, even though the count at the top suggested more.

That is the result count being an estimate. The search engine reports an
approximate total, which runs high, so the page count derived from it is an upper
bound rather than a promise. Press **Previous**: the results up to there are real.

## The buttons say the results are out of date

A reply's buttons and menus carry what you were looking at. After an update to
the bot changes how they do that, older replies answer "These results are out of
date". Run the command again; the new reply works as before.
