## Karte nachschlagen

Schlägt eine Karte per Name nach und postet sie in den Kanal: Kartentext,
Flavour-Text, Kosten, Lektion, Seltenheit, Legalität, Rulings und das Artwork.
Die Autovervollständigung schlägt beim Tippen Karten vor; wer einen Vorschlag
auswählt, sendet die Karten-ID - die genaue Schreibweise spielt dann keine
Rolle.

## Suche

Dieselbe Suche wie auf der Website, seitenweise in ein Embed gepackt, mit einem
Link zurück zu den vollständigen Ergebnissen auf revelio.cards. Filter lassen
sich kombinieren: Lektion und Set zusammen schränken auf beides ein.

## Deck nachschlagen

Zeigt ein öffentliches Deck per Link oder ID als Bild seiner Karten - dasselbe
Deck-Blatt, das im Deck-Builder unter "PNG exportieren" herauskommt, nach
Kartentyp gruppiert und mit der Anzahl auf jeder Karte. Das Embed darüber nennt
Charakter, Format und Legalität. Mit `view:list` kommt stattdessen eine
Textliste, die sich auf einer langsamen Verbindung besser liest und kopieren
lässt. So lassen sich nur öffentliche Decks nachschlagen - deine eigenen
privaten Decks listet `/mydecks` auf.

<CommandExample>/deck deck:https://revelio.cards/decks/abc123</CommandExample>

privat - nur du siehst das Ergebnis, auch in einem vollen Kanal. Für beide muss
dein Discord-Konto mit Revelio verknüpft sein.
